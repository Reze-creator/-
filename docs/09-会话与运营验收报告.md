# 会话与运营验收报告

验收日期：2026-11-07。本轮覆盖第二阶段和第四阶段的非 AI 部分；按用户要求暂不实现第三阶段 AI、RAG 与 AI 评测。

## 交付内容

- 设备模拟页面：正常/故障心跳，固定事件号的演示批次，按序、倒序和重复发送，手动事件与重试/跳过。
- 停车充电会话：入场、开始充电、累计电表、停止充电、离场，普通车位与充电车位分别校验。
- 最终账单：实际停车费、电费、预付款、模拟补退差额，车主查本人、管理员查平台。
- 运营中心：异常扫描、故障恢复后关单、操作审计、请求标识、当前进程接口指标。
- V2 增量迁移、设计与阅读指南、29 个业务操作的 OpenAPI/Apifox 文件、隔离压测脚本和原始结果。

## 本机隔离压测

原始结果：[performance/latest.json](performance/latest.json)。测量时间 2026-11-07 15:21:34（上海时间），临时实例 8091，独立 parking_test 库，完成后自动停止。正式实例 8090 和业务库 parking 未参加压测。

场景：带预约时间窗的资源查询，先预热 20 次且不计入统计，再计时请求 500 次，并发 20。

| 指标 | 实测 |
| --- | ---: |
| HTTP 200 | 500 / 500 |
| 计时请求总耗时 | 839.00 ms |
| 吞吐 | 595.95 请求/秒 |
| P50 | 30.59 ms |
| P95 | 52.17 ms |
| P99 | 65.60 ms |
| 最大 | 185.10 ms |

另外验证 20 个并发重叠预约得到 1 个成功、19 个预期冲突；20 次同幂等键创建只有 1 个预约 ID；20 次重复模拟支付均返回 CONFIRMED。脚本会取消自己创建的预约，不删除正式业务数据。

这只是单机、小种子数据量、短时资源读取的实测；不是持续负载、生产容量或设备事件写吞吐结论。延迟包含本机网络和客户端调度。后续扩大数据量与持续时间时应重新压测。
