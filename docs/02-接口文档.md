# 第一阶段接口契约

本文保留第一阶段的15个接口作为基线。当前预约还包含 IN_USE（使用中）、COMPLETED（已完成），支付记录离场后变为 SETTLED；入场后不能取消。新增14个接口、事件处理和结算规则见[会话与运营接口文档](08-会话与运营接口文档.md)。当前完整契约以 `openapi.json` / `apifox-openapi.json` 为准。

Base URL：`http://localhost:8090`。JSON请求；时间字段为ISO8601带时区字符串，响应统一UTC；金额单位元。

## 认证、响应和错误

登录/注册返回随机会话token。后续请求头为 `Authorization: Bearer <token>`，有效期24小时；登出立即失效。数据库只保存token摘要。公开接口：登录、注册、园区与资源查询、健康检查和OpenAPI。

统一响应：

```json
{"code":"OK","message":"success","data":{},"requestId":"请求跟踪ID"}
```

错误同样结构，data=null。不暴露SQL、堆栈、密码或token。可传X-Request-Id，安全字符且不超过64；它只跟踪请求，不参与业务幂等。

| HTTP | code | 含义 |
|---|---|---|
| 200 | OK | 查询、预约、支付、取消、更新成功 |
| 201 | OK | 注册成功 |
| 400 | VALIDATION_ERROR / BAD_REQUEST | 时间、长度、枚举、JSON不合法 |
| 401 | INVALID_CREDENTIALS / UNAUTHORIZED | 账号密码错误、未登录或会话过期 |
| 403 | FORBIDDEN | 普通用户调用管理接口 |
| 404 | NOT_FOUND | 资源不存在，或不是本人可操作的预约 |
| 409 | RESOURCE_UNAVAILABLE | 时段重叠 |
| 409 | IDEMPOTENCY_CONFLICT | 同用户同requestId改变了预约输入 |
| 409 | CONFLICT | 重复用户名、已停用、状态不允许操作等 |
| 503 | DEPENDENCY_UNAVAILABLE | 数据库暂时不可用 |

## 登录与注册

```json
{"username":"demo","password":"Demo@123"}
```

注册多传displayName；不允许传role，始终创建USER。username为3..32位ASCII字母、数字或下划线，密码8..64字符且UTF8不超过72字节，昵称1..40字符。

登录结果data：`token,expiresAt,user:{id,username,displayName,role}`。role为USER或ADMIN。密码使用BCrypt存储。测试账号见README。

## 资源查询

GET /api/resources：可选parkCode、type、startAt、endAt。type=PARKING/CHARGING。时间必须成对提供，并满足预约窗口规则。不传时间时available=null；传时间则返回true/false。公开列表不显示已停用资源；详情可以查看基础资料，但不能预约已停用资源。

资源对象：`id,code,parkCode,parkName,location,type,powerKw,hourlyRate,enabled,available`。

园区对象：`code,name,location,resourceCount`。数量包含园区全部资源，不代表当前时段余量。

## 创建预约

```json
{
  "requestId":"apifox-booking-001",
  "resourceId":"资源UUID",
  "plateNumber":"浙A12345",
  "startAt":"2026-11-08T09:00:00+08:00",
  "endAt":"2026-11-08T12:00:00+08:00"
}
```

日期示例需要换成测试当时的未来时间。requestId为1..64位字母数字下划线或连字符；车牌为5..10位中文、字母、数字，仅为演示格式校验，不校验真实号牌；字母统一转大写。

整点/半点开始，时长30分钟至24小时，最多提前30天。区间为[startAt,endAt)。创建时从资源读取价格快照，客户端不能传金额。普通与充电车位都仅按停车时长收费：hourlyRate×分钟数÷60，四舍五入到分。

同一用户相同requestId、相同输入返回已有预约，后续状态变化也返回当前状态；不再创建、不延长支付保留期。修改资源、车牌或时间返回409。网络重试复用原requestId，新业务尝试生成新requestId。

## 预约对象

```json
{
  "id":"预约UUID",
  "bookingNo":"PK业务单号",
  "resourceId":"资源UUID",
  "resourceCode":"A-001",
  "parkName":"云栖 · 科创园",
  "type":"PARKING",
  "plateNumber":"浙A12345",
  "startAt":"2026-11-08T01:00:00Z",
  "endAt":"2026-11-08T04:00:00Z",
  "hourlyRate":6.00,
  "amount":18.00,
  "status":"PENDING_PAYMENT",
  "holdUntil":"ISO时间",
  "paidAt":null,
  "cancelledAt":null,
  "createdAt":"ISO时间",
  "paymentStatus":"UNPAID",
  "canCancel":true
}
```

status：PENDING_PAYMENT / CONFIRMED / CANCELLED / EXPIRED。paymentStatus：UNPAID / SUCCESS / REFUNDED。canCancel由后端根据状态与开始时间计算，前端仅作展示，提交时仍会重新校验。

## 支付和取消

POST pay/cancel无需Body。支付在资源保留期内把待支付变为CONFIRMED，支付表同预约唯一；重复支付CONFIRMED返回原结果。到期支付返回HTTP200+EXPIRED，不创建支付单，前端应查看status。已取消预约不能支付，返回409。

取消仅本人可用。开始前待支付直接CANCELLED；已支付同时把payment改为REFUNDED；重复取消幂等。已开始不能取消，返回409。已过期取消返回EXPIRED。管理员可查看他人预约，但不能替他人支付或取消。

## 分页与管理

本人和管理预约列表支持status可选过滤，page默认1，size默认20，上限100；按createdAt、id降序。data：`{items:[],page:1,size:20,total:0}`。响应不暴露用户密码、会话或幂等摘要。

PATCH资源状态请求：`{"enabled":false}`，返回更新后的资源。停用不改变已有预约，因此已有预约仍可支付、取消。

## 数据表

app_user用户；user_session会话摘要；parking_resource资源；booking预约；mock_payment模拟支付。Flyway迁移位于backend/src/main/resources/db/migration/V1__schema.sql。MySQL资源行锁与事务防重叠，唯一约束保证同用户请求号和同预约支付不重复。
